# Features

## 1. Dynamic QR Codes with Hashids
- Short, clean QR codes using hashid slugs (e.g., `/r/Xy7Zp`)
- Editable destinations — update QR targets anytime without reprinting

## 2. Scanner Analytics & Tracking
- Track total scans, device type, OS, browser
- Peak scan times visualization

## 3. Gatekeeper Security System
- Login Wall — protect QR codes behind authentication
- Lead Capture — collect name/email before content access
- Premium branded viewer experience

## 4. Multi-Content Type Support
- Website URLs with preview
- PDF files with native viewer
- Business profiles with contact info
- WhatsApp direct messaging
- Password-protected content

## 5. User Dashboard
- MyCodes — manage generated QR codes
- MyFiles — file management
- Billing — payment/subscription management
- Admin dashboard
